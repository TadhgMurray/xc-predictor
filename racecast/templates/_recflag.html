{# ===================================================================== _recflag.html -- the PR / SR badge beside a time on a RACE page. Stamped by app.stampRecordFlags: is_pr means no earlier rated race by this athlete at this distance was faster, is_sr the same within the season. PR wins the badge; a row is never both. Same pill classes and tooltip machinery as the athlete page's flags, and the same tense: "when this race was run" -- a mark beaten later in the season was still a record on the day. ★ THE WORDS ARE TEXT, NOT aria-label (sweep 2026-10-10, B14): a label on a plain is skipped by several screen readers, so "PR" was read as the letters P R. The code is aria-hidden and the meaning sits beside it in .sr-only. Import with: {% from "_recflag.html" import recflag %} ===================================================================== #} {% macro recflag(row) -%} {%- if row.is_pr %} PRPersonal Record. Their fastest time at this distance when this race was run. {%- elif row.is_sr %} SRSeason Record. Their fastest time at this distance in this season, when this race was run. {%- endif -%} {%- endmacro %} {# --------------------------------------------------------------------- ratflag -- the same badge beside a RATING (owner, 2026-09-13). Stamped by app.stampRatingFlags. Not the same fact as the time badge: a time PR is bound to a distance, a rating PR is not, because comparing across distances and courses is what the rating is FOR. So a row can carry SR on its time and PR on its rating -- a season best on a hard course can still be the best they have ever run. ------------------------------------------------------------------- #} {% macro ratflag(row) -%} {%- if row.rating_pr %} PRPersonal Best rating. Their highest rating in any race when this one was run. {%- elif row.rating_sr %} SRSeason Best rating. Their highest rating this season when this race was run. {%- endif -%} {%- endmacro %}
